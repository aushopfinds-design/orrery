# FATE KEY — 7개 상품 내용 확인

이번 자료는 유료 리포트의 내용과 생성 결과에 대한 내부 검수입니다. 실제 결제부터 이메일·리포트 수령까지의 완료 확인, 외부 전문가 인증, 영어권 고객 대상 이해도 조사와는 구분합니다.

## 달라진 내용

- 종합·직업·사업 풀이에 앞으로 10년의 연도별 흐름을 추가했습니다. 일의 변화와 재물 활동, 늘어나는 부담을 나누어 읽습니다.
- 단순히 돈과 관련된 해라는 이유만으로 좋은 해라고 하지 않습니다. 타고난 특징과 긴 시기, 해당 연도가 특정 활동으로 연결되는지 확인합니다.
- 도움이 될 활동과 부딪히는 요구가 함께 있으면 둘 다 설명합니다. ‘기회와 주의가 함께 있는 시기’가 있을 수 있습니다.
- 12개월마다 일·돈·관계의 주제와 이유, 주의할 점을 설명합니다. 같은 경고를 달마다 복사해 넣는 방식은 줄였습니다.
- 고객 본문과 월별·긴 시기의 설명, 실천·주의 문구, 묶음의 통합 요약을 영어·한국어 같은 내용끼리 연결했습니다.
- 미리보기가 짧은 장의 나머지 유료 내용을 전부 보여주던 경우를 막았습니다.
- 출생시간을 모르면 그 부분을 빼고 판단하며, 긴 시기의 날짜도 대략적인 날짜로 표시합니다.

## 판매 판단의 범위

‘어떤 활동을 살펴볼 조건이 맞는지’와 ‘모든 일이 잘 풀리는 좋은 시기’는 다릅니다. 이번 풀이가 제공하는 것은 앞의 조건부 해석입니다. 돈을 벌 금액, 승진·창업 성공, 결혼·이별, 질병을 예측하거나 보장하지 않습니다. 근거가 부족한 경우에는 좋은 시기나 하나의 최종 판단을 만들어 채우지 않습니다.

| 상품 | 이번에 보강한 구매 내용 |
| --- | --- |
| 종합 인생 | 성향·강약점·돈·일·연애, 긴 시기와 앞으로 10년의 변화 |
| 궁합 | 두 사람 각각의 관점과 필요, 일상·돈·갈등, 같은 해가 다르게 작용하는 흐름 |
| 올해 운세 | 연간 일·돈·관계, 조건부 기회와 주의할 비교, 12개월의 서로 다른 설명 |
| 직업·재물 | 맞는 일·직장 환경, 이직·인정의 흐름, 돈 버는 방식과 10년 비교 |
| 사업 | 사업 방식·작은 시작·동업·수금과 제공 역량·확장·10년의 기회와 부담 |
| 성향·강점과 약점 | 성향·일상 부담·원하는 도움과 관계·강점이 약점으로 바뀌는 모습 |
| 전체 묶음 | 종합·궁합·올해를 연결한 통합 요약과 공통 자료 중복 정리 |

## 확인 자료

- `customer-passages-en.md`: 영어 고객 본문을 한 번에 읽는 자료
- `customer-passages-ko.md`: 같은 내용의 한국어 검수 자료
- `all-seven-en.md`, `all-seven-ko.md`: 실제 생성 결과 전체. 별도 계산 자료도 포함합니다.
- `claim-sentence-pairs.md`: 같은 내용을 연결한 한영 대조 자료
- `quality-checks.json`: 서로 다른 출생 정보 24개 × 7개 상품의 생성·대조 확인

계산 근거·제목·화면 설명·작성 방법까지 전체 문서를 완역했다는 뜻은 아닙니다. 고객 본문과 별도 계산 자료의 범위를 구분합니다.

## 운영 상태

새 풀이 전체는 별도 검수 화면에 반영합니다. 실제 판매 화면의 디자인·가격·결제 설정은 이번 작업에서 바꾸지 않습니다. 실제 판매를 열기 전에는 결제와 전달 과정을 따로 확인해야 합니다.

## 최종 내용 판단

전체 검사 747개가 통과했습니다. 7개 모두 현재 상품이 설명하는 전통적·조건부 해석의 범위에서는 내용 기준으로 판매 가능한 구성으로 판단합니다. 검사 개수만으로 외부 전문성이나 고객 만족을 인증하는 것은 아닙니다.

복잡한 경우에는 하나의 종합 판단이나 좋은 시기를 확정하지 않고 그 이유를 표시합니다. 외부 전문가 및 실제 미국·영국·호주 고객 대상 검수는 별도로 완료하지 않았습니다. 실제 판매를 열기 전 결제와 수령 과정을 따로 확인해야 합니다.
