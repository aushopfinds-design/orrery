**판정: Preview 기술 검수 통과. 요청한 ‘한국 정통 사주 수준의 전면 완성’을 기준으로 유료 출시는 보류합니다.**

계산 가능한 근거를 사용한 영어 본문, 상품별 내용 구분, 출생지·시간 미상 처리와 문서 제공은 개선했습니다. 그러나 이 버전은 십성의 반복, 뿌리의 유무, 월지의 오행, 합충형해파와 대운·세운을 설명하는 수준입니다. 계절·통근·투간·생극제화를 종합 가중하여 신강·신약·격국·용신을 판단하는 체계는 구현하지 않았습니다. 따라서 **기호의 반복을 ‘재물운이 강하다/해가 길하다’로 바꿔 말하지 않습니다.** 사용자 요청의 ‘운의 강약’을 전통적인 길흉·희기 판정까지 포함하는 의미로 보면 미충족입니다. 테스트가 통과했다고 이 부분까지 완성됐다고 말할 수 없습니다.

한국어 문서는 핵심 문단의 작성된 발췌 번역입니다. 7개 전체 한국어 완역본으로 표시하지 않았습니다. 전체 영어와 한국어 대조 화면은 인증된 관리자만 접근하며, 번역 공급자 호출에는 기존의 명시적 동의가 유지됩니다. 이번 검수에서는 실제 공급자 번역이나 Google 계정 로그인 세션을 호출하지 않았습니다.

이전의 가상 상황·자기계발 연습 페이지를 본문에서 제거했습니다. 각 장은 결론, 계산 설명, 생활에서 가능한 표현, 주의점과 확인할 사항으로 구성합니다. 같은 계산 특징에 같은 해석 문장이 적용되는 것은 의도한 규칙 기반 동작입니다. 개인화는 생일 숫자로 문구를 무작위 교체하는 방식이 아닙니다.

관리자 검수에는 문서 전체의 영어·한국어 대조 보기와 각 언어 전체 읽기를 함께 제공합니다. 기존 Google 인증, 허용 origin, 출처 서명, 번역 동의와 Preview 전용 조건은 유지했습니다.

## 검증과 정확한 범위

- 전체 로컬 테스트 **548 통과 / 0 실패 / 0 건너뜀**. 결제·주문·PDF 회귀 검사는 로컬 모의 환경으로 실행했으며 실제 결제는 하지 않았습니다.
- 새 검수: **서로 다른 24개 사주 × 7개 상품**, 6개 지역, 남녀와 시간 미상 6개 포함. 기존 60개 국제 사주 검사도 통과했습니다.
- 24개 사주의 2026·2027·2028년 **864개 월별 대표 시점**을 각각 코어 간지 및 십성 계산과 대조했습니다. 이것은 연결 정확도 검사이며 864개 독립 천문 관측과의 비교를 의미하지 않습니다.
- 기존의 독립 2026년 입춘 기준, 월주 경계, DST gap/overlap·역사적 DST 검사도 함께 통과했습니다. 새 검사는 New York·London·Sydney·Seoul의 알려진 DST UTC 변환과 계산 설명의 회귀 값을 확인합니다.
- 시간 미상에서는 입력 시각이나 시간주 placeholder를 바꿔도 본문이 같고, 모든 시간주·지장간·쌍 비교에서 제외됩니다.
- 지장간을 독립적으로 다시 열거해 십성을 확인했습니다. 중심 지장간과 숨은 줄기를 별개의 힘 점수처럼 중복 합산하지 않습니다.
- 세 글자가 필요한 형은 완성된 가지 집합에서만 기록합니다. 두 글자 비교로 완성된 삼형을 주장하지 않습니다.
- 새 버전의 첫 답변이 구판의 ‘Imagine’ 장면으로 시작하지 않는지, 상품별 질문이 다른지, Bundle의 공통 부록이 한 번만 나오는지 검사했습니다. 구판의 가상 상황을 의무화하던 편집 테스트는 새 요구사항에 맞게 수정했으며 테스트를 건너뛰지 않았습니다.
- TypeScript, 변경 구현 파일 ESLint, Vite 빌드, 정적 공개 페이지 21개 생성 통과. 기존 청크 크기 경고는 남아 있습니다.

## 남은 문제

1. **출시 판정의 핵심 미충족:** 신강·신약·용신과 희기 판단을 통합한 모델이 없어 ‘어느 시기가 더 유리한가’를 정통 사주의 강약·길흉으로 판정하지 않습니다. 임의 점수나 근거 없는 길흉 표현으로 채우지 않았습니다.
2. **시기 해상도:** 매월 15일 12:00 Asia/Seoul은 대표 비교점입니다. 절입일부터 다음 절입일까지의 전체 월운이나 사건 날짜를 계산하지 않습니다. 1월이 전년 간지에 속할 수 있음을 본문에 표시합니다.
3. **해석의 성격:** 규칙 기반 문화 해석이며 실제 사건에 대한 예측 성능을 검증한 것은 아닙니다. 미래 소득·질병·결혼·이별은 확정하지 않습니다.
4. **번역/실사용 검수:** 한국어 샘플은 발췌입니다. 실제 관리자 계정으로 로그인하고 공급자 번역을 끝까지 수행하는 실사용 검증은 미실행입니다. 인증·배치 순서·중단 후 재개·언어 전환은 로컬 DOM 및 API 모의 검사로 확인했습니다.
5. **반복의 한계:** 공통 원리와 같은 십성의 해석은 여러 고객에게 반복됩니다. 본문 내 완전히 동일한 문장은 줄였지만 모든 고객의 모든 문장이 고유하다고 주장하지 않습니다.
