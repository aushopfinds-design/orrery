## 수정

- 형(刑) 명칭 표: 선택한 전통 표기에서 丑戌未는 恃勢, 子卯는 無禮로 정정했다. 寅巳申의 無恩은 유지했다. 두 지지만 비교하는 고객용 근거에서 세 지지의 형이 완성됐다고 표현하지 않는다. 직접 확인되는 충 등 다른 관계는 유지한다.
- 대운은 기존에도 성별 설정을 사용했다. 계산을 새로 도입한 것이 아니라 실제 입력한 Male/Female 설정, 연간 음양과 순행/역행을 기록과 계산 설명에 공개했다. 궁합에서는 두 사람 각각 표시한다.
- 실제 입력 시각, 보정된 계산 시각, 분 단위 보정량을 공개한다. 뉴욕 기본 예시는 1998-03-25 03:00 → 02:57, 己丑이다. 현 엔진의 시주 경계는 03:30이며 인접 시주는 己丑/庚寅이다. 통상적인 03:00 경계와 다른 관례라는 점을 명시했다. 경계 15분 이내의 사례에 안내한다. 기존 시간 계산 알고리즘은 변경하지 않았다.
- 한국 입력은 기존 KST 표준시 경로를 유지하며 역사적 서머타임 보정을 설명한다. 해외 입력은 IANA 시간대, 경도와 근사 균시차 경로를 설명한다. 출생시간 미상은 시주를 추정하지 않으며 대운 시작 시점이 근사값임을 밝힌다.
- 연간·월간 표의 `12:00 Asia/Seoul`은 출생지와 별개인 공통 비교 기준 시계임을 설명한다. 시간대를 숨기지 않는다.
- 종합 리포트의 빠진 `08 · Your Life Chapters` 제목과 목차를 맞췄다.
- 쉬운 영어 용어 설명을 추가했다. 웹에서는 펼쳐 보기, PDF에서는 독립된 용어 페이지를 제공한다.
- 12개월마다 다른 실행 과제·유지할 것·주의할 것·검토 질문을 넣었다. 출생 차트의 관계 주제는 관계 장에 유지하며 같은 문장을 매달 반복하지 않는다.
- PDF 상황 안내의 동일한 한계 문장 반복을 줄였다. 상황은 가상의 연습이며 출생정보로 실제 사건을 알아낸다는 주장을 하지 않는다는 안내와 해석의 한계는 유지한다.
- PDF 근거는 동일한 그룹을 한 번씩 뒤쪽 부록에 모으고 본문에서 내부 링크로 연결한다. 모든 원문 근거는 유지한다.
- PDF 페이지는 개별 리포트 기준 `Report page N of M`으로 표기한다. 통합본 앞에 이 의미를 설명한다. 세 가지 질문마다 실제 필기할 수 있는 넓은 두 줄을 제공한다.
- 페이지 수를 세는 이전 캔버스 상태 재생 방식이 링크·책갈피를 1페이지로 묶는 결함을 확인했다. 측정 후 정상적으로 다시 조판하는 방식으로 바꾸고 이동 대상을 검증한다.

전통 명칭 검토 기준: [三命通會 卷二](https://zh.wikisource.org/zh-hant/三命通會_(四庫全書本)/卷02)의 三刑 설명. 전승에 따라 명칭이 다른 예가 있으므로 선택한 표기라고 명시한다. 이는 전통 문헌의 분류 확인이며 과학적 타당성이나 독립 전문가 감수를 의미하지 않는다.

## 검증

- 앱 Vitest: 417개 통과. 계산 설명·알려진 경계·역사적 DST·미상 시각·실제 대운 방향·12개월 간지·월별 과제·08번 제목의 회귀 사례를 포함한다.

- 모든 8,844개 등록 본문 문단의 추출 일치, 글자 경계, 대체 글자, 페이지 번호와 책갈피·링크 목적지를 검사한다. 7종의 전체 페이지 연락 시트와 대표 실제 크기 페이지를 시각 점검한다.

## 샘플 재발급

```bash
node scripts/export-samples.mjs
```

기본 출력은 체크아웃 옆 `output/pdf/`, ZIP은 `output/The-Fate-Key-All-Samples.zip`이다. 빌드된 모델을 직접 사용하며, JSON 중간 산출물에 Git SHA와 수정 여부를 기록한다. 조판에는 ReportLab·PyMuPDF·pypdf·Pillow와 Noto Sans/Serif가 필요하다. 검증 결과와 연락 시트는 `node_modules/.cache/fate-samples/`에 남는다.

결제·가격·SNS 애니메이션·광고 활성화·AdSense 신청은 이번 수정에 포함하지 않는다.
