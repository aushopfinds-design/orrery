# FATE KEY r10 — 상품별 풀이와 한국어·영어 병렬 작성

## 구현

계산된 사주 → 언어 독립 분석 계획 → 한국어 검수 풀이 / 영어 고객 풀이. 한국어 작성부는 영어 원문을 입력받지 않는다. 두 출력의 analysisId는 같은 계획의 SHA-256이다. 공유 계획에는 원국, 위치별 십성·지장간, 신강약 신호, 월령 격국 후보, 선택 대운, 세운·월운, 충돌과 균형 방향이 들어간다. 분석 ID 일치는 입력 일치를 검증하며, 문장 의미 일치를 자동으로 보증하지는 않는다.

7개 상품을 고객 질문 중심으로 구성했다. Complete는 인생·강약점·재물·직업·관계·전환점, Compatibility는 끌림·차이·일상·갈등·관계 흐름, Year는 총운·재물·직업·관계·지원/주의 달과 12개월, Career는 적성·직장·이직·승진·돈·연간 흐름, Business는 적성·창업·동업·재물·확장·대운·주의, Wellbeing은 기질·오행·감정·인간관계·생활 강약점이다. Bundle은 세 풀이를 연결하고 공통 영어 부록을 한 번 제공한다.

## 이전과 이후

r9는 영어 풀이와 영어 기반 번역 검수가 중심이었고 긴 구조 설명이 첫 장에 노출됐다. r10은 공유 분석 계획에서 두 언어를 각각 작성하며, 상품별 질문과 짧은 구조 요약을 먼저 제공한다. 전체 계산 설명은 근거에 남긴다. 이직·승진·창업·확장을 각각 계산된 시기와 연결했다. 지원하는 달은 원국·대운·월운의 조건부 방향이 맞고 별도 마찰이 없는 경우에만 구분한다.

## 검수 자료

- all-seven-en.md: 가상 입력으로 생성한 고객 영어 전체 출력.
- all-seven-ko.md: 같은 분석 계획에서 작성한 한국어 전체 출력.
- seven-products-en-ko.md: 실제 발췌 비교.
- sample-manifest.json: 입력·기준연도·분석 ID·출력 길이.

한국어는 영어의 문단별 완역이 아니라 별도 작성된 더 짧은 검수 초안이다. 모든 영어 문장에 대응하는 한국어 번역본을 제공하는 단계는 아니다. 관리자 화면에서 두 전체 출력을 동시에 볼 수 있고 언어별 전체 보기도 가능하다. 인증과 허용 Origin을 유지한다. 외부 번역 호출 없이 생성되며 기존 선택 번역 API는 호환성을 위해 남긴다.

## 검증

전체 Vitest 605/605 통과. 24개 서로 다른 명식에서 개인화·연도/월의 실제 간지·조건부 시기 분류를 검사했다. 출생지/서머타임/시간 미상과 기존 결제·인증·PDF 회귀 검사가 포함된다. 새 병렬 작성 및 목차 검사는 48개다. TypeScript, 변경 구현 ESLint, Vite와 공개 샘플 생성 성공. 인증된 실제 Google 사용자 세션의 수동 검수와 실제 결제는 실행하지 않았다.

## 남은 문제와 출시 판정

한국식 분석 기반의 병렬 작성 구조와 상품 목차는 Preview 검수 가능하다. 그러나 신강약은 보수적인 자체 FATE-qualitative-r1이며 24개 모두 확정 판정한 것이 아니다. 격국 성패, 조후, 특수격, 합화와 최종 용신을 완성했다고 볼 수 없다. 후보와 미확정을 그대로 표시한다. 근거 없는 좋은 해·강약 점수·사건 보장은 추가하지 않았다. 한국어 문장 자연스러움과 두 언어의 모든 해석 범위에 대한 사람의 검수도 완료되지 않았다.

따라서 완성된 정통 명리학 유료 리포트로서의 전면 출시 판정은 보류한다. 이번 변경은 구조와 콘텐츠 개선이며 운영 배포·가격·디자인·실제 Stripe 설정 변경을 포함하지 않는다.

24개 명식을 하나의 테스트로 묶은 실행이 기본 제한 시간을 넘긴 사례가 있어, 같은 검증을 명식별 24개 독립 테스트로 분리했다. 검증 항목을 삭제하거나 제한 시간을 늘리지 않았다.
