# The Fate Key — 구매 흐름 개편

## 구현된 흐름

홈의 무료 입력 → 실제 출생 정보로 만든 무료 결과 → 개인 보고서 일부 미리보기 → 내용·예정 가격·전체 예시 비교.

- 가장 먼저 Complete Life Reading 하나를 소개한다. 별도 질문이 있는 고객에게 궁합, 직업·돈, 연간 보고서를 보여준다. 세 보고서 묶음은 별도 제안으로 표시하고 사업·일상 균형 보고서는 접어서 제공한다.
- 무료 결과에서 개인 미리보기로 바로 이동한다. 같은 탭에서 출생 정보를 다시 입력하지 않고 보고서 종류를 바꿀 수 있다.
- 개인 미리보기는 입력한 사람의 계산 결과를 사용한다. 공개 전체 예시는 기존의 가상 인물 자료를 유지하고 구분해서 안내한다.
- 궁합과 묶음은 실제 두 번째 출생 정보를 추가해야 비교한다. 다른 사람의 입력이 첫 번째 사람의 저장된 폼을 덮어쓰지 않는다.
- 연간 보고서는 선택한 연도와 12개월의 계산된 참고 시점 제목을 보여준다. 시간 미상인 사람의 시주 해석은 제외한다.
- 무료와 전체 버전의 차이, 보고서 목차, USD 예정 가격, 예정된 단건 구매 방식과 제공 형식을 구체적으로 안내한다.
- 긴 주제 설명과 전문 차트는 필요할 때 펼쳐볼 수 있다. 기존 브랜드 그림과 반짝임 효과는 유지한다.

## 아직 연결되지 않은 부분

실제 결제와 결제 확인 후 개인 전체 보고서 발급은 아직 제공하지 않는다. Vercel 프로젝트에는 결제용 환경 변수가 없고 Stripe 연결 로그인도 완료되지 않았다. 결제 연결 전에는 가격을 예정 가격으로 표시하며 결제 버튼, 결제 완료 상태 또는 구매 권한을 만들어내지 않는다.

이번 브라우저 저장에는 출생 정보와 선택 연도만 포함한다. 개인 보고서 ID, 영수증이나 유료 권한은 포함하지 않는다. 이는 유료 발급을 보호하는 서버 구현을 대신하지 않는다. 실제 결제 발급은 Stripe 연결을 완료한 뒤 서버에서 결제 확인, 주문 저장, 반복 통지 처리, 접근 권한과 전달 실패·취소·재시도를 검증해야 한다.

## 이후 확인할 성과

결제 연결 뒤에는 무료 결과 도달률, 개인 미리보기 도달률, 결제 시작률, 결제 성공률, 발급 성공률을 각각 확인한다. 보고서 발급 성공까지 확인해야 구매 흐름이 완료된 것이다. 현재 이 수치를 수집하거나 구매 증가를 측정한 것은 아니다.
