# FATE KEY r11 — 격국·균형용신 검토와 한영 핵심 문장 검수

## 실제 완료한 작업

월령의 투간 중심, 확인된 식상–재성·재성–정관·관성–인성·식신–편관 관계, 투출 관계의 경쟁을 별도 데이터로 기록한다. 이는 관계가 함께 있다는 근거이며 특정 격국의 성패를 자동 인증하지 않는다. 월령 격국과 억부 균형용신은 별도 상태로 관리한다.

일반 명식의 조건부 균형 기운은 신강약 방향과 투출·지장간 근거를 요구한다. 계절 조후, 시간 미상, 특수 구조, 월지 마찰, 격국 중심의 천간 합, 경쟁하는 투출 관계가 판단을 흔들면 단일 오행을 선택하지 않는다. 격국 중심이 확정되지 않은 사실만으로 별개의 억부 판단까지 자동 취소하지는 않는다. 대운·세운·월운에서 조건부 기운과 실제 기운을 비교하고 별도 마찰을 유지한다. 점수·수익률·행운 날짜는 만들지 않았다.

격국·균형용신, 선택된 개인 강점/약점, 연간·월간 핵심 판단을 두 언어의 문장 쌍으로 연결했다. 두 문장이 실제 출력에 남아 있는지 검사하며 누락 시 관리자 생성에서 오류를 낸다. 같은 분석 ID만으로 의미가 같다고 간주하던 점을 보완했다. 관리자 전체 대조 보기에는 핵심 문장 대조를 추가했다.

## 실제로 발견하고 고친 문제

1. 영어 반복 제거가 궁합의 2029년 B 주의 문장까지 없앴다. 시기별 장에서 문장 의미가 손실되지 않도록 반복 제거를 제한했다.
2. 공동 재정 한국어 풀이에 감정 관계 설명이 섞였다. 돈의 관계를 설명하도록 수정했다.
3. 개인의 강약점 자리에 직업·거래 부담을 반복하던 한국어 문구를 일간 성향의 강점/약점으로 수정했다.
4. 일상 스트레스 자리에 직업 적성 문구를 사용하던 한국어 풀이를 생활 균형 설명으로 수정했다.
5. 같은 해의 연간/7월 판단이 같은 문장 ID를 쓰던 검수 식별자 충돌을 수정했다.

## 결과 자료

- all-seven-en.md / all-seven-ko.md: 7개 상품의 전체 실제 출력. 한국어는 별도 작성한 더 짧은 풀이이며 영어 전체의 문장별 완역이 아니다.
- claim-sentence-pairs.md: 샘플 전체의 핵심 문장 118쌍. Bundle에 포함된 3개 리포트의 재등장도 포함한 수다.
- population-audit.json: 서로 다른 가상 명식 24개의 입력·강약·격국·균형용신 결과와 보류 이유.
- sample-manifest.json: 입력·분석 ID·언어별 길이·문장 수·대조 범위.
- test-results.json: 최종 자동 검사 결과.

## 검수 범위와 판매 판정

24개 명식에서 7개 상품(168개 생성 경로)을 실제로 생성해 핵심 문장 대조와 출력 누락을 검사했다. 신강약은 supported 3 / support-needed 2 / mixed 11 / deferred 8이었다. 이번 단일 균형용신 정책은 실제 24개 모두 withheld였다. 합성 기호 회귀 사례에서만 조건부 우선 기운이 선택되는 경로를 확인했다. 실제 고객의 대부분에 단일 용신을 제공할 수 있다고 주장할 근거는 없다.

이번 보강은 좁은 일반 명식 정책과 실제 한영 오류를 개선한 것이다. 격국의 모든 성패·구응, 조후의 개별 용법, 종격·전왕격·합화 전체를 구현한 것이 아니다. 핵심 문장 검수도 전체 영어 설명의 완역·문장별 외부 전문가 검수와 같지 않다. 검수 문장은 수작업으로 대응시켰고 출력 포함 여부와 수치·시기 일치는 자동 검사한다. 자동 검사는 영어 뉘앙스의 모든 오류를 판별하지 않는다.

따라서 “정통 격국·용신 전체 완성 및 두 언어 전 문장 검수 완료” 기준의 유료 출시 판정은 계속 보류한다. 기능 개선은 Preview에서 검수할 수 있다. 운영 사이트·디자인·가격·실제 Stripe 설정은 변경하지 않았다. 실제 Google 사용자 로그인과 실제 결제는 실행하지 않았다.
