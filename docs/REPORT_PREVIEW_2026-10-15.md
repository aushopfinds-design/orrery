# 결제 전 보고서 내용 확인 흐름

## 사용자 요청

첫 화면에서 무료 풀이와 실제 보고서 샘플을 더 쉽게 찾고 읽을 수 있게 한다.

## 변경

- 첫 소개 문단에 `Start My Free Reading`과 `Read a Report Example`을 함께 배치한다.
- 상품 목록 앞에 성격·일·관계 문단을 읽을 수 있는 예시를 둔다. 문단과 근거 설명은 연결된 전체 예시와 같은 출생 정보 및 보고서 생성 함수에서 가져온다.
- 가상 출생 정보로 만든 공개 예시임을 문단 위와 아래에 알린다. 예시의 선택한 주제에서 해당 전체 장으로 바로 이동한다.
- 본인 무료 결과에 본인 사주로 생성한 짧은 관계 문단을 추가하고 개인 보고서 미리보기로 연결한다. 오행 수치는 선택해서 펼쳐볼 수 있게 한다.
- 무료·전체 비교표의 관계 항목을 실제 제공 범위에 맞춘다. 영어를 기본으로 하며 공유 문구를 여섯 언어 사전에서 사용한다.
- 기존 그림, 애니메이션, 입체적인 표면 표현 및 상품 가격 체계를 유지한다. 결제·보고서 구매 권한은 이번 변경 범위가 아니다.

## 확인

- `npm test`: 기존 23개 파일, 357개 테스트 통과.
- `npm run build`: TypeScript 및 Vite 운영 빌드 통과.
- `git diff --check`: 공백 오류 없음.
- React 점검: 계산은 입력이 바뀔 때만 수행하고, 홈 예시를 별도 지연 로딩한다. 주제 버튼에는 선택 상태와 연결된 콘텐츠를 표시하고, 네이티브 펼치기·키보드 초점·44px 이상 조작 영역을 사용한다. 추가 네트워크 요청이나 개인정보 URL을 만들지 않는다.
