# 7개 상품 — 새 구조 분석의 영어·한국어 대조

r9 가상 샘플. 아래는 새 분석 부분의 발췌 대조이며 7개 리포트 전체 한국어 완역본은 아닙니다. 영어 전문은 all-seven-en.md에 있습니다. 한국어는 검수용으로 작성했으며 공급자 번역을 호출하지 않았습니다.

**주의: 조건을 명시한 자체 보수적 규칙입니다. 정통 명리학 전체의 합의나 전문가 검증을 받았다는 뜻이 아닙니다.**

No balancing-element preference is assigned while the support judgement is unresolved. A missing element is not automatically a useful element.

**English — actual 2027 reference and active cycle**
