## 판단 기준: FATE-qualitative-r1

이 규칙은 **검수를 위해 선택한 자체 보수적 규칙**입니다. 모든 한국 명리학 학파의 공통 공식이거나 논문에서 검증된 분류기라는 뜻이 아닙니다. 표준으로 확립되지 않은 숫자 배점·확률·강약 점수를 만들지 않았습니다.

- 지원받는 쪽으로 기우는 판정: 월지 중심 십성이 인비에 해당하고, 중심 지장간에 일간과 같은 오행의 뿌리가 있으며, 일간을 제외한 천간에도 인비가 드러남.
- 지원이 필요한 쪽으로 기우는 판정: 월지 중심이 식재관에 해당하고, 같은 오행 뿌리가 없으며, 드러난 천간에 인비와 식재관이 함께 있음.
- 완전한 무지원·지원 일변도 또는 완성된 삼합·방합은 특수 구조/합화를 따로 판단해야 하므로 보류. 시간 미상도 보류.
- 위 조건에 맞지 않으면 혼재. 힘의 크기를 연속 점수로 추정하지 않고 모르는 부분을 유지.
- 강약 경향이 정해져도 용신을 하나로 찍지 않음. 지원받는 경향에서는 식재관, 지원이 필요한 경향에서는 인비를 억부 후보군으로 설명할 뿐, 그 모든 관계가 무조건 희신이라고 하지 않음.
- ‘부족한 오행=용신’, ‘편재=사업가’, ‘재성=돈을 번다’, ‘충=실패’를 사용하지 않음.

24개 실제 날짜 기반 가상 명식의 분포는 **지원 경향 3 / 지원 필요 경향 2 / 혼재 11 / 보류 8**입니다. 따라서 24개 전부를 신강/신약으로 분류했다고 주장하지 않습니다. 합성 명식 테스트는 규칙의 분기 검증이며 실제 인생 결과나 학파 간 정답을 검증한 것이 아닙니다.

## 시기 해석의 연결

1. 원국에서 지원 경향을 계산합니다.
2. 각 대표 날짜의 실제 연주·월주를 사용합니다.
3. 그 날짜가 대운의 실제 계산 시작일시 이상, 다음 시작일시 미만인지 확인합니다. 시작 연도만 같다고 아직 시작되지 않은 대운을 적용하지 않습니다.
4. 원국의 경향과 진행 대운·해당 시기의 지원/부담 관계가 같은 방향일 때만 조건부 해석을 제공합니다.
5. 충·형·해·파가 있으면 별도 주의를 유지합니다. 합이 있어도 성공이나 결혼을 보장하지 않습니다.
6. 시간 미상, 강약 혼재, 특수 구조 보류, 진행 대운 범위 없음은 유리·불리 판정도 보류합니다.

‘강약 경향’과 ‘좋은 사건의 확률’은 다릅니다. 대표 날짜는 월·연도 전체를 덮지 않으며 정확한 사건 시점도 아닙니다. 월운의 전체 절입 구간, 조후 계절의 세밀한 가중, 합화 성립, 격국 성패와 구응은 아직 구현하지 않았습니다. 이 제한을 조건 없이 덮고 ‘가장 좋은 해/가장 나쁜 해’를 붙이지 않았습니다.

월령·통근·투간 분석과 대운/세운의 연결은 생겼습니다. 하지만 이것을 실제 전문가의 종합 명리 판정이나 검증된 예측 모델로 판매할 수 있다는 결론은 아닙니다. 원국의 강약 경향을 명확히 판정하지 못하는 경우가 많으며, 확정 격국·단일 용신/희신·조후·특수격·합화 성패까지 완성됐다고 표시하지 않습니다.
