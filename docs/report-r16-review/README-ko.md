이번 작업은 반복 줄이기, 질문에 답부터 하기, 개인별 계산 근거를 쉽게 설명하기 세 가지로 제한했다. 새 기능이나 새 운세 점수를 추가하지 않았다.

## 고객에게 달라진 점

- 종합·직업·사업의 재물 풀이가 각 상품의 질문에 답한다. 특히 사업운의 매출·이익 일반 상식을 빼고, 실제로 함께 나타난 재물과 배움·지원의 특징이 왜 운영 부담으로 해석되는지 설명했다.
- 사업의 시작과 확장, 직장에서 인정받는 방식은 질문의 답을 먼저 읽고 시기 풀이를 뒤에 읽는다.
- 일을 감당할 바탕은 출생 계절, 같은 기운의 뿌리, 겉으로 드러난 역할을 함께 설명한다. 출생시간이 없거나 따로 살펴야 하는 구성은 강약을 단정하지 않는다.
- 궁합은 사적인 친밀감과 일상을 맞추는 정도를 실제 두 사람의 비교에서 나누어 결론 낸다. 두 사람의 감정이나 관계 결과를 단정하지 않는다.
- 성격 상품은 직업 목록보다 개인적인 필요와 일상의 요구가 만나는 모습을 설명한다.
- 시기별 변화는 그 시기의 주제와 타고난 업무·관계 부분이 어떻게 만나는지 연결한다. 연도·월·긴 시기를 새로 좋거나 나쁘게 만들지 않았다.
- 조언 상자는 실제 결정을 살펴볼 장에 골라 남겼다. 화면·영어 전체 출력·한국어 검수본에서 같은 선택을 적용했다.
- 묶음은 재물의 구조, 해당 연도의 요구, 관계에 필요한 배려와 일이 겹치는 달을 연결한다. 포함된 세 리포트는 각자의 자세한 풀이로 남는다.
