# The Fate Key — 구매자 관점 리포트 내용 검수

검수일: 2026년 10월 16일, 호주 시드니 기준.

이 기록은 AI가 구매자 입장에서 직접 내용을 읽고 수정한 편집·기능 검수다. 실제 유료 고객 설문, 영어권 독자 인터뷰, 명리 전문가 인증이나 예측 정확도 검증을 뜻하지 않는다. 결제와 유료 발급은 이번 작업 범위에 포함하지 않는다.

## 발견한 부족점

1. 성향 설명과 좋은 습관은 있어도, 실제 선택에서 두 방법을 비교할 기준이 부족했다.
2. 무엇을 말하고 기록해야 하는지, 결과가 어떤 모습이면 접근을 바꿔야 하는지가 약했다.
3. 개인화가 설명에 집중돼 있었다. 실천 내용과 대화문도 해당 차트의 해석 주제와 연결할 필요가 있었다.
4. 가까운 관계에서 내가 받고 싶은 도움을 요청하는 말과, 상대에게 도움을 제안하는 말이 섞일 수 있었다.
5. 조언이 맞지 않는 상황을 독자가 확인하고 다른 방법을 선택할 여지가 더 필요했다.

## 보강한 실제 고민 18가지

| 리포트 | 상황 1 | 상황 2 | 상황 3 |
|---|---|---|---|
| 종합 | 좋은 선택지 두 가지 사이의 고민 | 내 계획이 계속 뒤로 밀릴 때 | 작은 약속이 커졌을 때 |
| 직업·돈 | 이직 제안의 불명확한 조건 | 업무가 늘어나는 상황 | 직무 변경과 근무 환경 변경의 구분 |
| 사업 | 첫 상품·서비스를 작게 시험하기 | 수정·후속 업무의 확대 | 협업에서 결정과 업무의 주인 정하기 |
| 연애·궁합 | 반복되는 작은 다툼 | 함께하는 시간과 개인 시간 | 계획·알림·마무리까지 포함한 역할 분담 |
| 연간 | 여러 목표의 우선순위 | 새 책임과 기존 약속 | 바쁜 해에 관계를 이어가는 방법 |
| 일상 균형 | 중단이 많은 하루의 마무리 | 바로 승낙하기 전에 확인할 것 | 일정이 바뀌어도 유지 가능한 작은 습관 |

각 상황에는 다음 내용을 넣었다.

- 상황을 알아볼 수 있는 구체적인 문제와 질문.
- 실제 계산된 차트 주제의 연결 설명, 개인 질문과 출처.
- 선택지 두 가지와 각각 맞는 조건·치러야 할 대가.
- 바로 써볼 대화문과 작은 실천 계획.
- 실제 사실을 적을 세 가지 질문.
- 접근을 유지해도 되는 관찰 결과와 바꿔야 하는 관찰 결과.
- 이 연습이 잘 맞지 않을 수 있는 조건.

## 개인화의 범위

- 태어난 날의 기호, 태어난 달의 주된 관계와 안쪽 관계, 필요한 경우 태어난 해의 관계를 사용한다.
- 궁합은 실제로 입력된 두 사람의 필요와 양방향 비교를 사용한다. 한 사람의 설명으로 상대를 판단하지 않는다.
- 연간 리포트는 선택한 연도의 실제 계산 기준과 두 연간 주제를 사용한다. 일반 생활 질문과 관계 질문도 포함한다.
- 질문뿐 아니라 직업 조건 비교, 사업의 첫 실험, 관계 대화문, 실천 단계 일부도 해당 해석 주제에 따라 달라진다.
- 동일한 해석 근거를 가진 사람에게는 같은 주제가 나올 수 있다. 생일 숫자를 임의로 섞어 다른 결과처럼 만들지 않는다.
- 상황 자체는 독자가 선택하는 예시다. 생일만으로 취업 상태, 관계 문제, 사업 현황을 알아냈다고 표시하지 않는다.
- 모르는 출생시간은 실천 페이지에서도 사용하지 않는다. 고급 강약·격국·용신을 새로 판정했다고 주장하지 않는다.

## 구매자 입장에서 확인하는 기준

| 질문 | 이번 보강의 확인 지점 |
|---|---|
| 내 고민에 가까운 내용을 찾을 수 있나? | 카테고리에 맞는 세 가지 상황 선택 |
| 왜 내 리포트에 이 설명이 나왔는가? | 계산된 주제, 연결 설명, 펼쳐 볼 수 있는 출처 |
| 두 선택 중 무엇을 비교해야 하나? | 맞는 조건과 장단점이 함께 있는 선택지 |
| 대화에서 무슨 말을 할 수 있나? | 구체적인 문장과 두 사람 각각의 요청 |
| 읽고 나서 무엇을 할 수 있나? | 작은 계획과 세 가지 기록 질문 |
| 조언이 안 맞으면 어떻게 하나? | 맞지 않는 조건과 접근 수정 기준 |
| 기록해 두고 다시 사용할 수 있나? | 선택한 계획 복사, 전체 미리보기 복사, 인쇄용 내용 |

## 검증의 한계

자동 검사는 입력·분기·출처·출력의 일관성과 정해 놓은 문장 기준을 확인한다. 구매자가 실제로 만족했는지나 돈을 내고 살지는 확인하지 못한다. 실제 영어권 독자 반응, 명리 해석의 전문가 검토, 결제 후 발급·재열람 검증은 별도 단계다. 모든 항목이 객관적으로 9.5점 이상이라는 인증이나 점수 보장은 하지 않는다.

## 구현 후 확인 기록

- 자동 검사: 29개 파일의 400개 검사 통과. 타입 검사와 프로덕션 빌드 통과.
- 서로 다른 출생정보의 질문·실천 변화, 안쪽 월 관계의 차이, 같은 해석 근거의 일관성, 두 사람 교환, 미상 출생시간 제외, 연도 변경, 카테고리별 주제 일치를 확인했다.
- Chrome 브라우저 안에서 360·390·430픽셀 폭으로 공개 샘플과 개인 미리보기의 126개 상황 화면을 확인했다. 실제 휴대폰 기기에서 실행한 검사는 아니다.
- 1100픽셀 폭의 데스크톱 상황 화면 21개를 확인했다.
- 각 상황의 선택지 2개·실천 3단계·기록 질문 3개, 본문 글자 크기, 복사 버튼 크기, 가로 넘침을 확인했다.
- 가상 출생정보를 입력하는 실제 화면 흐름으로 개인 미리보기와 두 사람 미리보기를 만들었다.
- 샘플을 바꾸면 근거와 실제 실천 문장이 함께 바뀌는지, 2028년을 선택하면 그 연도의 계산 기준과 내용이 함께 바뀌는지 확인했다.
- 상황 탭의 키보드 이동·초점, 번들 안의 세 리포트 대상·상황 전환·목차 복귀를 확인했다.
- 선택한 계획 복사와 전체 개인 미리보기 복사를 각각 실제 붙여넣기로 확인했다. 계획 복사에는 선택한 상황만, 전체 복사에는 세 가지 상황이 들어간다. 미리보기 표시와 미발급 안내가 유지되며 Markdown 강조 기호가 남지 않는다.
- 실물 프린터 출력, 결제와 유료 발급, 실제 구매자의 만족도와 전환율은 이번 검사에 포함하지 않았다.
