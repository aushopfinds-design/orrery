# 리포트 내용·개인화 개선 — 2026-10-16

대상은 The Fate Key이며, 판본은 `2026.10-r2`다. 결제 연결 전 리포트의 반복감과 핵심 안내를 개선했다.

## 실제로 확인한 약점

기본 뉴욕 예시의 main chapters에서 Keep close / Watch out for 28개 중 직업 12개, 사업 8개가 다른 장과 동일했다. 연간 24개 중 9개, 궁합 32개 중 8개, 일상 균형 20개 중 4개도 반복됐다. 이는 본문 전체의 유사도 점수나 구매 만족도 측정이 아니라 정확히 같은 안내 문장 수다. 서울·시드니, 시간 미상 예시에서도 반복을 확인했다.

## 변경

- 리포트 앞에 `Your focus, in plain English`를 넣었다. 두 주제를 함께 설명하고, Try first / Pause and clarify if / Review after the attempt 순서로 읽는다.
- 종합·직업·사업·일상은 실제 월간 십신과 월지 본기 십신을 함께 사용한다. 연간은 선택 연도의 7월 15일 12:00 Asia/Seoul 기준 연간 십신과 원국 월간 십신을 비교한다. 마지막 확인 질문에는 일간의 기존 개인 주제를 반영한다.
- 5개 편집 주제군의 15개 조합은 협업·시도·약속·책임·학습 사이의 실제 선택 문제를 설명한다. 같은 두 근거에는 같은 의미를 사용한다. 날짜를 임의로 섞거나 이름만 바꿔 독창적인 척하지 않는다.
- 행동과 중단 조건은 상품별로 별도로 작성했다. 직업은 역할·업무·보수·지원, 사업은 고객 문제·제공 결과·납품, 일상은 반복 업무와 생활 선택, 연간은 개인 계획과 재검토를 다룬다. 공통된 두 주제라도 카테고리의 실행 과제는 다르다.
- 궁합은 두 사람의 일지에서 기존에 설명하던 대화 필요를 함께 읽는다. 편집상 5개 대화 유형, 15개 조합을 사용해 공동 대화 형식을 제안한다. 이는 새로운 전통 궁합 분류·등급·점수·실제 관계 진단이 아니다. Person A/B를 바꾸면 필요와 근거도 정확히 바뀐다.
- 장별 안내를 해당 장의 판단 기준으로 다시 작성했다. 60개 가상 차트 × 6종에서 주요 장의 정확한 안내 중복이 없음을 검사한다. 연간 검사는 12개월도 포함한다.
- 월별 안내는 각각 핵심 유지 항목과 주의 항목 한 개씩으로 집중했다. 계산된 월별 주제·두 번째 주제·실행 과제·점검 질문·정확한 간지와 근거는 유지한다.
- 개인 미리보기, 전체 리포트, 정적 공개 샘플, 복사 텍스트, PDF가 같은 핵심 안내를 사용한다. 미리보기에서는 나머지 본문을 추가로 노출하지 않는다.
- PDF는 표지·전체 기록에 있는 출생정보를 첫머리에서 한 번 더 반복하지 않는다. 목차 뒤의 일반 안내 한 줄이 페이지를 독점하던 문제도 정리했다. 초기 페이지의 고립된 안내는 조판 검사로 감지한다.

## 검증과 한계

- 앱 테스트 424개 통과. 새 검사에서는 180개 가상 차트에 대해 핵심 안내를 비교한다. 동일한 일간·주된 월간 주제에서 두 번째 주제군이 바뀔 때 종합 해석과 검토 질문이 바뀌는지 확인한다.
- 출생시간 미상은 입력 시각을 바꿔도 핵심 안내가 바뀌지 않는다. 연간 기준과 궁합 상대가 바뀌는 실제 경로를 확인한다.
- 타입 검사와 프로덕션 빌드, 공개 경로 12개 생성에 성공했다. 공개 샘플 6종의 초기 HTML에 핵심 안내 세 항목과 근거 펼치기가 모두 들어간다.
- PDF 24종과 통합본은 기존 조판 검사와 시각 검토를 거친다. 원문 문단, 글자 경계, 문자 표시, 내부 링크, 목차와 페이지 번호를 확인한다. 실제 파일과 ZIP은 검증된 최종 Git SHA에서 재발급한다.
- 계산 엔진과 시간 관례, 결제·가격·광고·SNS 애니메이션은 변경하지 않는다.
- 자동 검사와 가상 사례는 실제 구매자 조사나 영어권 독자 검토를 대신하지 않는다. 9.5점의 구매 만족도·과학적 타당성·전문가 인증을 주장하지 않는다.
- 현재 관리형 환경에 `$control-browser`가 없어 브라우저/실기기 검증은 하지 않는다. 반응형 CSS, 정적 HTML·컴포넌트 출력, PDF 실제 렌더 검증과 구분한다.

재발급 명령은 `node scripts/export-samples.mjs`다. 기존 샘플 파일의 동일한 이름과 저장 항목을 갱신한다.
