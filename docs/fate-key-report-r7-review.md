# FATE KEY r7 — 7개 유료 상품 콘텐츠 검수

검수일: 2026-10-23 (Australia/Sydney)

## 적용 기준

- 구매자가 상품을 선택하며 궁금해한 질문에 먼저 답한다.
- 일상 상황, 행동·감정의 해석, 실제 계산 근거, 실행할 선택을 연결한다.
- 계산하지 않은 신강·신약, 격국, 용신이나 사건 발생 확률을 만들어 내지 않는다.
- 수입 구조, 직장 선택, 고객에게 제공할 사업의 형태를 서로 다른 질문으로 다룬다.
- 한 장의 조언이 다른 장의 결론을 대신하지 않게 한다.

## 상품별 검수 결과

| 상품 | 고객 질문과 이번 수정 |
| --- | --- |
| Complete Life Reading | 성향·일·관계·돈·대운을 각각 다른 근거로 설명한다. 재물 장에 정재·편재의 구별, 실제 일과의 연결, 연도별 비교와 근거를 보강했다. |
| Love & Compatibility | 두 일주와 두 월주를 실제로 비교한다. 합과 충이 함께 있는 경우 둘 다 설명하고, 개인적인 반응과 일상 운영이 서로 다른 모습을 보일 수 있음을 풀었다. |
| Year Ahead | 6개 본문 장과 12개 월별 기준을 검수했다. 월별 문단의 중복을 없애고, 연간 요약·부록의 근거를 맞췄다. 출생 월의 성향과 추가되는 연간 주제를 명확히 구분했다. |
| Career & Money | 적합한 업무 조건, 기여를 보여주는 방법, 급여 형태, 재물 상징과 시기, 피드백을 구분한다. 급여·프로젝트 수입의 차이를 설명하고 연도별 비교의 원문 근거를 추가했다. |
| Business Reading | 제안의 형태, 고객 수요, 협업, 납품·후속 업무, 새 제안과 반복 업무의 시기를 각각 다룬다. 직장인의 급여 상담으로 사업성을 대신하지 않는다. |
| Everyday Balance | 일간의 강점과 압박, 오행별 실험, 출생 월의 작업 환경, 일지의 관계 욕구를 장별로 나눠 사용한다. 같은 압박 문장을 한 장에서 두 번 쓰던 부분을 없앴다. |
| Complete Bundle | 3개 원본 리포트 앞에 종합 편지를 추가했다. 출생 차트의 성향, 선택한 연도의 추가 주제, 두 사람의 관계를 함께 읽는다. 샘플·구매 PDF·관리자 검수에 같은 종합 편지가 포함된다. |

## 시기 해석의 계산 범위

- 연간 재물 비교: 기준 연도부터 최대 5년, 각 7월 15일 12:00 Asia/Seoul의 연주를 비교한다.
- 월별 비교: 선택 연도의 각 15일 12:00 Asia/Seoul을 별도로 계산한다.
- 연간·월간 천간과 지지의 정기를 일간에 대조한다. 본문의 시기 언급에 실제 갑자·십성·기준일을 근거로 남긴다.
- 월별 표본은 절기 경계나 한 달 전체 구간을 뜻하지 않는다. 재물 상징이 없는 해도 수입과 기회가 있을 수 있다.
- 시간 미상일 때 시주를 쓰지 않으며, 대운 시작일의 기존 근사 표기는 유지한다.

## 전달 경로

영어 리포트 생성 함수가 사이트 샘플·미리보기·구매 리포트·PDF·관리자 검수의 공통 원문이다. 한국어 검수는 그 원문을 블록 단위로 전달하며 사주를 재계산하지 않는다. r7 판본과 문서 내용으로 검수 digest가 달라지므로 이전 원문의 한국어 풀이를 새 원문에 재사용하지 않는다.

이미 발급한 주문의 보관 리포트는 기존 불변성 정책을 유지한다. r7 확인은 새 리포트 생성이나 관리자 검수 생성에서 진행한다.

## 검증

- 보고서·관리자 검수·결제 전달 관련 25개 테스트 파일, **218개 테스트 통과**.
- 60개 국제 출생 차트에 대한 내용 차이, 시간 미상 제외, 월별 계산·반복 문장 검사 포함.
- 관리자 인증 전 접근 차단과 영어 원문 블록 일치 검사 포함. 실제 Google 계정 로그인이나 AI 제공업체의 한국어 번역 품질을 자동 테스트로 인증한 것은 아니다.
- 7개 상품 모두 결제 제공업체를 대체한 테스트 환경에서 리포트와 다운로드 가능한 PDF 생성 확인. 실제 Stripe 거래를 실행한 검사는 아니다.
- 각 PDF가 r7을 포함하고, Bundle PDF가 종합 편지를 포함함을 텍스트 추출로 확인했다.
- 생성 PDF의 종합 편지·오행·재물·연간 도입 페이지를 이미지로 확인했다. 기존 편지지 문양·강조·페이지 번호가 유지됐다.
- TypeScript 프로젝트 빌드, Vite 빌드, 공개 페이지 생성 통과.
- Preview 기능 브랜치에만 반영한다. 가격·결제 설정·운영 도메인 변경은 포함하지 않는다.

이번 검수는 생성 코드와 대표 출력의 편집·일관성 검수다. 원어민 구매자나 외부 명리 전문가의 유료 상품 승인 기록으로 사용하지 않는다.
