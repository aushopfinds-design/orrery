# FATE KEY · 고객 검수 반영본 (2026-10-24)

세 차례 검수의 공통 지적에 따라 기존 계산과 상품 구성은 유지하고, 고객이 실제로 읽는 풀이를 다시 정리했습니다. 운영 사이트, 가격, 실제 결제 설정은 변경하지 않았습니다. 새 원고는 검수용이며 고객 만족이나 전문가 검수를 통과했다는 뜻은 아닙니다.

## 무엇이 달라졌나

- 각 장은 질문에 대한 답으로 시작합니다. 직업과 사업은 같은 직업 목록을 반복하지 않고 업무 방식, 직장 조건, 창업, 동업, 확장이라는 서로 다른 질문에 답합니다.
- 재물은 고정 수입, 고객·거래 수입, 두 방식의 공존, 안쪽에 있는 재물 글자, 직접 근거가 없는 경우를 구분합니다. 재물 글자가 실제로 어느 생활 영역에 있는지도 짧게 설명합니다.
- 한 해의 긴 설명을 여러 장에 복사하지 않습니다. 중요한 시기는 앞에서 요약하고 전체 10년 흐름에 자세한 설명을 모읍니다. 10년의 모든 연도와 12개월은 유지했습니다.
- 일반 샘플 페이지와 상세 리포트 화면 모두 월별 핵심을 표로 먼저 보여 줍니다. 가장 주의해서 볼 세 달은 실제로 겹치는 부담의 수로 골랐으며 나머지 달을 평온하거나 안전하다고 바꾸지 않았습니다. 전체 12개월의 설명과 근거는 그대로 있습니다.
- 화면에서 같은 실천 문장이 본문·옆 상자·실천 상자에 거듭 나오던 부분도 한 번만 보이도록 정리했습니다.
- 공통 안내는 각 독립 리포트에 한 번 둡니다. 매년 해고·손실·이별을 보장하지 않는다고 반복하던 문장은 없앴습니다. 실제로 무엇을 주의할지는 남겼습니다.
- 궁합 본문은 ‘본인/상대방’과 ‘you/your partner’로 읽습니다. 새 이름 입력 기능을 추가하거나 실제 고객 개인정보를 수집하지 않았습니다. 두 방향의 끌림과 각자의 필요는 계산 결과에서 따로 풀이합니다.
- 묶음의 통합 설명은 요약문을 다시 인용하지 않고, 타고난 업무와 해당 연도의 요구가 같은지, 업무와 사적인 관계의 부담이 같은 달에 겹치는지 연결해 설명합니다.
- 한국어와 영어는 같은 풀이 결과를 공유합니다. 계산 부록과 방법 설명의 전체 일대일 번역까지 완료한 것은 아닙니다.

## 비교 수치의 의미

`editorial-metrics.json`은 기존 원고와 새 원고의 단어 수와 똑같은 긴 문장의 반복을 비교합니다. 65자보다 긴 줄을 기준으로 하며 제목과 월별 요약표는 제외합니다. 뜻이 비슷한 문장까지 모두 잡는 검사는 아니고, 고객 만족도 점수도 아닙니다. 표에는 월별 핵심을 다시 보여 주기 때문에 원래 설명과 일부 겹칩니다.

24개의 서로 다른 출생 정보로 비교했을 때 직업·사업·월별 시기의 기존 분류는 모두 동일했습니다. 주의할 시기를 임의로 좋은 시기로 바꾸지 않았습니다. 출생시간을 모르는 경우에도 시간을 추측해 유리한 시기를 만들지 않습니다.
