## Implementation

`src/depth.css` loads after the established homepage stylesheet. All new rules are inside `@media screen`, so the existing print/PDF styling and pagination remain in control. No image assets, report copy, prices, route behavior, chart calculations or payment functionality changed. No new packages or JavaScript effects were introduced.

Pointer hover effects apply only to fine pointers. Reduced-motion preferences remove the new transitions and movement, while static depth remains visible. Existing illustration animation and its pause controls retain their own settings. Existing keyboard focus treatments remain, and form focus receives a visible ring. High-contrast mode retains solid control boundaries.
