# The Fate Key — 애드센스 신청 전 점검

기준일: 2026년 10월 16일, 호주 시드니.

대상은 `https://thefatekey.com`이다. NOWSCOPE의 신청이나 검토 상태는 변경하지 않는다. 애드센스 신청 제출, 광고 활성화, 결제 기능 개시는 하지 않는다.

## 결론

**사이트의 공개 콘텐츠와 기술 준비를 보완했다. 실제 게시자 ID와 운영자가 승인한 공개 문의 주소가 제공되지 않아 신청 직전 확인 항목이 남아 있다. 승인 완료나 승인 가능성 보장을 뜻하지 않는다.**

## 발견한 문제와 조치

## 현재 공개 경로

홈, 소개, 읽는 방법, 개인정보 안내, 사용 범위, 샘플 목록과 카테고리별 전문 6종. 기본 설정에서 총 12개 경로다. 개인 입력·세션·사람의 프로필 정보는 정적 공개 페이지나 사이트맵에 쓰지 않는다. 공개 예시는 뉴욕 1998년·런던 2000년의 가상 입력이고, 연간 기본 예시는 2027년이다.

## 운영자가 확인해야 할 남은 항목

1. 기존 AdSense 계정에서 `thefatekey.com`을 추가했는지, 계정·사이트에 어떤 요구사항이 표시되는지 확인. 이번 작업은 계정의 실제 화면이나 검토 상태를 확인한 작업이 아니다.
2. 사이트 연결에 사용할 실제 `pub-...` 또는 `ca-pub-...` 게시자 ID 확인. 없으면 소유권 확인 완료로 표시하지 않는다. Google은 메타 태그·광고 코드·ads.txt 등 안내되는 방법을 제공한다.
3. 공개해도 되는 문의 이메일과 운영자 표시 확정. 가짜 이메일이나 미확인 법인·인증을 공개하지 않는다. 실제 주소가 설정될 때만 `/contact/`와 그 링크를 게시하도록 준비했다. 문의 주소는 신뢰·지원상의 권고이며, 이 문서가 Google의 독립적인 필수 페이지 수 규정을 주장하는 것은 아니다.
4. 콘텐츠를 실제 영어권 독자가 읽어 보는 편집 검토. 자동 검사나 AI 검수를 실제 고객 조사·전문가 인증·사람의 수동 편집 검토로 바꾸어 말하지 않는다.
5. 광고를 실제로 켜기 전 광고가 들어갈 페이지·위치와 동의 설정 확인. 개인정보·도움말·입력만 있는 화면·미완성 페이지에 자동으로 광고를 뿌리는 방식으로 준비하지 않는다. EEA·영국·스위스의 맞춤형 광고는 Google 인증 CMP 요건을 확인해야 한다. 단순 쿠키 확인 버튼으로 이를 충족했다고 표시하지 않는다.

## Google 공식 근거

- [신청 전 페이지 준비](https://support.google.com/adsense/answer/7299563?hl=en): 독창적·유용한 내용과 사용하기 쉬운 탐색.
- [사이트가 광고 준비 상태가 아닐 때](https://support.google.com/adsense/answer/12176698?hl=en): 접근·코드·콘텐츠·정책 문제와 검토 요청 절차.
- [사이트 연결](https://support.google.com/adsense/answer/7584263?hl=en): 실제 계정의 소유권 확인 방법.
- [광고 쿠키 관련 필수 안내](https://support.google.com/adsense/answer/1348695?hl=en): Google·제3자 광고 쿠키와 광고 선택 안내.
- [콘텐츠 없는 화면의 광고 정책](https://support.google.com/publisherpolicies/answer/11112688?hl=en): 저가치·미완성·행동 전용 화면 및 수동 검토·선별 없는 자동 생성 콘텐츠에 대한 유의점.
- [EEA·영국·스위스 동의 관리](https://support.google.com/adsense/answer/13554116?hl=en): 맞춤형 광고의 인증 CMP 요건.
- [Google의 자바스크립트 SEO 안내](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics): 서로 다른 본문을 프래그먼트로만 로드하는 경로의 발견 한계.

페이지 수, 글자 수, 트래픽의 임의 기준을 승인 보장 조건으로 만들지 않는다. 사이트가 수정됐다는 사실과 Google이 승인했다는 사실은 별개다.

## 구현 검증

- 기존 리포트·시간대·개인화 검사를 포함한 자동 검사 408개 통과.
- 공개 페이지의 독립 주소, 실제 모델 원문의 장·상황·출처, 12개월, 두 사람 대상, 소유권 검증과 광고 표시의 분리, 가짜 문의 주소 방지, 사이트맵과 개인정보 안내를 검사.
- 타입 검사와 빌드 통과. 공개 전문은 입력이나 자바스크립트 실행 없이 읽을 수 있는 HTML로 빌드된다.
- Chrome 브라우저에서 360·390·430픽셀 너비의 36개 화면과 1100픽셀 너비의 데스크톱 12개 화면을 확인했다. 실제 휴대폰 기기 검사는 아니다.
- 공개 전문·안내 11개 페이지의 본문은 17px이며 자바스크립트 없이 표시된다. 페이지 가로 넘침은 없다. 기존 앱의 비교표는 자체 가로 스크롤 영역 안에서 읽는 구조다.
- 실서비스와 같은 배포 미리보기의 12개 공개 주소, robots.txt와 sitemap.xml이 HTTP 200으로 응답함을 확인했다. ID 미설정 상태의 ads.txt는 404이며, 가짜 파일로 통과 처리하지 않았다.
- 상황별 목차 이동, 출처 펼치기, 정적 샘플에서 기존 대화형 샘플로 이동, 앱 하단에서 샘플 목록으로 복귀, 개인정보 안내에서 실제 브라우저 데이터 관리 화면으로 이동을 확인했다. 데이터 삭제 버튼은 실행하지 않았다.
- 전체 빌드에서 내부 페이지 링크·섹션 앵커·고유 ID를 확인했다. 계정 검토 요청이나 광고 활성화는 실행하지 않았다.
