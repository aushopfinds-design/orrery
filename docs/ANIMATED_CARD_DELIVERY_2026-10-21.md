## 구현

정지 PDF, 개인 화면, PNG, MP4가 DestinyCardArtwork의 같은 레이아웃과 카드 데이터를 사용한다. 별도 열쇠 이미지에 가로축 회전 효과를 적용한다. 테두리에는 금빛이 흐르고 별 12개는 서로 다른 간격으로 반짝인다. 화면에는 재생/정지와 시스템 동작 줄이기 설정이 적용된다. PDF는 정면의 정지 카드다.

구매자 페이지에서 PNG/MP4 저장 전 기존 서버 report API를 다시 호출한다. 주문 접근키는 Authorization 헤더로만 전달하며 URL이나 영상 서비스로 보내지 않는다. 서버 검증 응답의 선택된 카드만 렌더링한다. 미구매 개인 미리보기에는 개인 파일 발급 버튼이 없다. 공개 샘플 다운로드는 DESIGN SAMPLE 워터마크를 유지한다.

영상은 고객 브라우저 안에서 Canvas + MediaRecorder로 생성한다. H.264 MP4를 지원하는 브라우저에서 1080×1350, 약 6초, 무음 영상이 만들어진다. 직접 프레임 캡처를 사용한다. 파일 헤더의 ftyp를 검증한다. 기기 호환성이 없으면 안내와 이미지 저장을 제공하며 WebM을 MP4로 위장하지 않는다. 저장 중 탭 숨김, 중단, 오류가 발생하면 파일 발급을 중단하고 트랙과 타이머를 정리한다.

## 검증

- 전체 38개 테스트 파일, 484개 테스트 통과 (68.30초).
- TypeScript, 변경 소스 ESLint, Vite 빌드 및 21개 공개 경로 생성 통과.
- 7개 상품 결제/리포트 테스트 포함. 구매 후 접근 재검증 성공/거절 UI 테스트 추가.
- Preview에서 공개 샘플 PNG와 MP4 버튼을 실제로 눌러 다운로드했다.
- PNG: 1080×1350 RGBA.
- 최종 MP4: H.264, 1080×1350, 5.9779초, 1,753,866바이트, 182프레임, 평균 약30.45fps (가변 프레임 간격).
- 원본 MP4 PTS/DTS가 모두 증가함을 확인했다. 입력 시간 단위 1:30000을 보존한 디코딩 검사 통과. 앞/옆 방향 프레임을 확인했다.
- 회전 CSS 적용, 정지 버튼의 상태 전환 확인.
- Complete 검수 PDF: 30페이지, 1,080,381바이트, 텍스트 페이지 경계 오류0. 카드29쪽 시각 검수.

## 실제로 하지 않은 검증

실물 Android/iPhone 전체 검사, 새 원격 Stripe 결제, 기존 비공개 주문키를 새 Preview로 전송하는 검사는 하지 않았다. 주문 접근 경계는 서버/화면 자동 검사로 검증했고, 원격 렌더링과 다운로드는 가상 정보의 공개 샘플로 검증했다. 브라우저 MP4 호환성을 모든 기기에 보장하지 않는다.

## 이미지 출처와 편집

기존 승인 카드 the-fate-key-sample.webp를 입력으로 내장 imagegen 편집 도구를 사용했다. 배경은 public/images/cards/destiny-background-v2.webp, 투명 열쇠는 public/images/cards/destiny-key-v2.png로 저장했다. 원본 이미지는 보존했다.

배경 프롬프트: 기존 4:5 카드의 글자/테두리/산/호수/나무/초승달 구도를 유지하고 중앙 금빛 열쇠만 제거해 배경을 복원한다. 나무와 초승달은 제거하지 않고, 새로운 기호나 문구를 추가하지 않는다.

열쇠 프롬프트: 기존 중앙의 둥근 장식과 네 방향 보석, 덩굴 장식 축, 오른쪽 이빨을 가진 금빛 열쇠만 앞면으로 추출한다. 링 안쪽을 포함한 실제 알파 투명 배경을 만들고 하늘/별/나무/달/문자/테두리를 제거한다. 기존 열쇠 형태를 따른다.
