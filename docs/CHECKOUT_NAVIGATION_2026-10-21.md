# 구매 진입 화면과 동선 구현

7개 상품 카드의 가격 바로 아래에 독립된 구매 CTA를 추가했다. 기존 미리보기/전체 예시 링크는 유지한다. Preview의 버튼은 Test purchase, 일반 호스트에서는 Buy report로 표시된다. 상품 상세 페이지와 개인 미리보기에서도 구매 흐름으로 진입할 수 있다.

`checkoutHash(kind)`는 개인 미리보기 경로에 `-checkout`을 붙인다. 기존 미리보기와 예시 경로는 유지하고 상품별 구매 경로를 추가로 해석한다. 상품을 바꿔도 구매 의도를 유지한다.

선택 상품명과 가격을 위쪽에 표시한다. 필요한 출생 정보를 입력하면 결제 영역으로 스크롤하고 키보드 포커스도 이동한다. 궁합과 패키지는 상대방 정보가 필요하며 입력 전 결제 영역을 열지 않는다. 구매 경로에서는 긴 상품 목차를 접어서 정보 입력에 바로 접근하게 한다. 단계와 입력 완료 버튼도 Checkout / Continue to checkout으로 표시한다.

비공개 Sandbox 접근 코드는 계속 필요하다. 공개 코드, 결제 우회, 클라이언트 paid 플래그는 추가하지 않았다. 접근 코드 없는 버튼은 비활성 상태이며 이유를 읽을 수 있다. 일반 호스트에서는 구매 미개시 안내를 표시한다. 실결제 모드나 운영 도메인을 변경하지 않았다. 운영사이트가 실제 고객 결제를 받는 상태가 됐다고 해석해서는 안 된다.

검증: TypeScript, 변경 파일 ESLint, Vite 빌드와 공개21경로 생성 통과. 구매 동선/구매자 화면/상품 경로/개인 미리보기/6개 언어 키 검사64개 통과. 배포 브라우저에서7개 구매 CTA를 확인하고 Career & Money의 상품 버튼 클릭 → 가상 정보(1998-03-25, 시간 미상, America/New_York) 입력 → USD10.99와 테스트 결제 영역 노출을 확인했다. 실제 코드나 고객 접근키는 브라우저에 입력하지 않았고 새로운 결제는 실행하지 않았다.
